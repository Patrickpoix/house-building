# Oak Veneer 01 背板对照试验

来源：[Poly Haven — Oak Veneer 01](https://polyhaven.com/a/oak_veneer_01)，作者 Jenelle van Heerden，页面标注 CC0；2026-11-08 获取。官方图块宽 1.8 m；本目录保留 4K Diffuse、2K Rough 和 2K OpenGL Normal 原图。完整解码与 Blender 路径检查通过，颜色为 sRGB，数据图为 Non-Color。

在 `stages/S003/bookshelf-refinement/` 的背板对照中，纹理覆盖范围较大，但同镜头近景的木纹对比过强，与白橡木侧板不协调；此材质方案暂不作为当前较优版本。该结论仅针对现有模型、光照和视角，不代表素材本身不适合其他用途。
