# 资产质量基准

正式入库按 B 级实用标准，以实际观察距离验收；Tripo 统一 2K PBR，现有其他来源的原始贴图保留。视频用于结构与覆盖核对；36 类、143 模块分别统计，重复实例只计一次。

## 逐件检查

1. **结构与尺度**：整体轮廓自然，比例合理，支撑、连接和布料挂放可信。以米制记录宽、深、高，使用 Z 向上和合适的落地或安装轴心。主体变形、沙发正反重复坐垫、椅腿缺失、明显错误布料结构或尺寸离谱须修复。
2. **材质与贴图**：在房间灯光下材质协调、UV 和 2K PBR 正常显示。颜色图用 sRGB，数据图用非颜色数据。按材质提供 Base Color、Roughness、Metallic 和 Normal 信息，均匀的参数可使用明确的常数。允许隐蔽面细节欠缺、轻微 UV 接缝、轻微色差和不显眼的局部纹理瑕疵。严重贴图异常、缺失材质或明显拉伸须修复。
3. **实景与交付**：主要角度和实际房间镜头中无显眼穿模、悬空或异常。归档能打开的 BLEND、可回导的 GLB、贴图和可追溯的参考，使用实际链接或实例装入房间。通过即入库，结束该件打磨。
4. **项目抽查**：整屋最终验收从正式资产记录随机种子抽取不少于 5 件，保存近景并检查实际可见的结构和材质。单件常规验收只补渲解决疑问所需的角度。

## 统计规则

- **资产类别**：结构或用途可独立识别的资产类型，至少 36 类；颜色复制不能单独计类。
- **预览模块**：资产库中可识别、可独立调用并有真实差异的模块或变体，至少 143 个；复制同一对象到多个位置不算新模块。记录资产 ID、变体差异、文件、实际尺寸和场景使用位置。
- 视频明确标注的项目逐项映射；辨认不了的内容保留为待复核，不能假造编号、尺寸或材质。每件最终模型需关联参考、贴图、验收记录和住宅实例。
- 每件使用「待制作」「修复中」「阻塞」「已正式验收」之一。诊断记录说明缺陷属于参考、几何、UV、PBR 或比例。同一路线两次实质调整无明显改善时，保留原始模型和较优候选，换工艺或标明阻塞后做下一件。
- 成品需整体可渲染、场景实例真实引用资产库，且抽样放大检查通过；上面的数值是最低门槛，不替代审美判断。
