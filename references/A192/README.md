# A192 窗边豆瓣绿

原件为 [Codex 内置 `image_gen.imagegen` 的生成参考](four-view-original.png)，分辨率 1254 × 1254。具体模型子版本未披露。

提示指定同一株约 28 cm 高的豆瓣绿，以正、左、背、右四向正交白底、柔和均匀光照呈现。三根主茎、带短叶柄的厚椭圆叶片、盆土与细小珍珠岩，搭配约 13 cm 直径的砖红卷沿陶盆和分离托碟。

四向的盆体和三根主茎可互相核对，部分叶片位置无法逐一对应。以该图确定轮廓和构造，在 Blender 独立制作主茎、叶柄、叶片、盆土、陶盆和托碟。叶脉、叶面粗糙度及陶釉采用原创 2K PBR。
