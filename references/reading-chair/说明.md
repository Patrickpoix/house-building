# 起居阅读椅参考候选

用途：S001 起居阅读区的独立座椅，目标外形约宽 0.76 m、深 0.82 m、高 0.78 m，座高约 0.42 m；尺寸为设计目标，尚未验证可坐性。浅橡木框架、暖亚麻色坐垫和靠垫，优先保留木结构与软垫的独立关系。

`three-quarter.png` 为 Codex 内置生图工具生成的候选主视图；工具未披露模型版本，不能认定为 Images 2.6。提示内容：单件写实阅读椅，四腿落地的浅橡木框架、连续扶手和柔和倒角，独立亚麻坐垫与略后倾靠垫，白色背景及柔和均匀光照，整椅三分之四视角；不加文字或其他物件。尺寸只是文字约束，图中比例须在各视角与建模时复核。

候选并非正式资产。多视角须检查扶手、椅腿、横梁及软垫轮廓一致后才能提交生成；Tripo 输出仍须检验尺度、结构、纹理及房间实景。

`front-candidate.png`、`side-candidate.png`、`back-candidate.png` 由内置生图工具以 `three-quarter.png` 为输入生成。统一提示要求保持同一椅子的比例、木色、亚麻面料、软垫轮廓及缝线、扶手、四腿和连接，白底柔光，不添加物件；分别指定正面居中、左侧正交和背面居中视角。检查发现背面出现多余椅腿，侧面坐垫明显超出前腿，而主视图没有同等程度外凸；原始候选未作为完整多视角输入。

定向编辑产生 `side-revised.png` 与 `back-revised.png`：分别要求侧面坐垫前缘与前腿齐平、背面保留四条腿，其余特征不变。侧面前缘得到改善；背面腿部仍有重叠歧义，未用于生成。Tripo 实际使用正面和修订侧面，结果及缺陷见 `tripo/outputs/reading-chair/QUALITY_REVIEW.md`。

## 2026-11-08 参考来源与结构复核

六张候选均来自同一张 AI 主视图及其派生编辑，并非六个独立实物视角；不可据图片张数推断隐藏结构已被证实。联系表总览后，按原像素对比 `back-candidate.png` 与 `back-revised.png` 的 `(350, 500, 800, 500)`：修订图左侧仍有重叠的腿形，两侧横梁下各可见内侧腿形，无法可靠对应四条腿。该局部不能单独确定各形状是否真实椅腿；背面连接、榫接与座垫支撑均缺少可靠证据。侧面修订仅解决可见前缘外凸，不能证明扶手、后腿和背框连接一致。

本轮结论：背视候选暂不作为正式多视角输入；保留原图及已生成模型，先寻找与设计相容、来源清楚的真实结构视角或依据设计尺寸建立可检查的三维结构引导。真实参考用于结构启发时须区分不同实物，不能冒充同一椅子的实拍；推断部位须标注并经结构检查。之后再制作一致标准视图，以原始高质量图输入 Tripo；本轮未生成新图或消耗积分，也未证明首次合格率提高。
