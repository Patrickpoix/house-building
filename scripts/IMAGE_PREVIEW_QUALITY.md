# Codex 图片轻量预览：保真边界与验证记录（2026-11-08）

## 用途与硬性质量边界

本工具只减少**模型查看图片的传输与历史负载**，绝不改变 Images 2.6 正式参考、Tripo 正式输入、GLB、UV、2K/4K PBR、Blender 工程或最终渲染原件。**“预览能看懂”不等于“资产验收通过”。** 若联系表与原图判断冲突，以原图、实际模型、结构数据和正式房间渲染为准。禁止为了节省上下文跳过关键缺陷、减低模型精度、降低最终验收标准。

1. **快速总览**：目录调用 `D:\Python\python.exe scripts\preview_views.py <目录>`，生成一张带视角名称的小联系表。仅用于发现轮廓、方向、整体比例、多视角明显矛盾与候选筛选。每视角约460×320显示区域，不足以判断织纹、缝合、精细结构。
2. **高保真单图观察**：将目录换为单张PNG/JPG/WebP路径。输出JPEG质量95、**4:4:4色度采样**、LANCZOS缩放（仅超出1280像素边长时），优先用于查看次级结构与材质整体效果；这是**有损**压缩，不能作为像素级验收。不可把轻量预览重新输入Tripo当成参考原图。
3. **真正的细节复核**：`--crop X Y WIDTH HEIGHT` 从原始图片取无缩放、无损PNG局部。对于接缝、木构连接、纹理畸变、法线、粗糙度、背面多余结构等问题，至少查看相关部位原像素，并检查模型几何与独立PBR贴图；需要检查整体上下文时打开原始整张图。
4. **正式验收**：仍依照AGENTS.md和assets/资产质量基准.md对原始资产、正侧背结构、UV/PBR、真实物理尺度、房间环境和足够分辨率的近景进行核对。预览图不得作为唯一验收证据，不能单靠 PSNR 判断建模质量。

图片生成工具（包括 Images 2.6）可能**先返回完整高清图**再保存文件，本脚本不能减小该工具第一次已经返回到会话的负载。应当保留必要生成能力，减少**重复回读**并按需扩大复核，不应禁止高质量正式图片生成。对网页或命令的巨大文本输出也采用按需摘要，而不是回传全部日志。
