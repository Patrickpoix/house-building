# 任意组装指南 — 把 PBR 资产当积木拼成不同房屋

> 本工程的价值不止于 `scene/house.blend` 这一栋固定住宅，而在于 **36 类 / 144 个完整 4K·8 通道 PBR 资产** 加上一套「改配置就换一栋房」的组装器。
> 换房型、换面积、换隔墙、换家具，都只改一份 JSON，不碰任何建模代码。

## 一、核心模型

```
assets/_library/asset_library.blend      144 个 AST_ Collection（资产积木，完整 4K PBR）
assets/_textures/<材质>/*_*.png          16 材质 × 8 通道 = 128 张 4096×4096（共享贴图）
assets/catalog.csv                        144 个资产的唯一索引（ID / 类别 / 尺寸 / 材质）
        │
        ▼  按 ID 挑选、按坐标摆放
scene/layouts/<房型>.json                 一栋房屋的配置（房间 / 隔墙 / 窗 / 资产清单 / 相机）
        │
        ▼  blpython src/02_scene/assemble.py -- <布局.json>
scene/assembled/<房型>.blend              组装好的新房屋（可继续在 Blender 里精修）
scene/assembled/<房型>.png                预览渲染
```

**一句话**：布局 JSON 是图纸，`asset_library.blend` 是积木箱，`assemble.py` 是组装工。三栋示例房屋已经证明同一套积木能拼出完全不同的房子。

## 二、三套开箱即用的布局

| 布局文件 | 房型 | 面积 | 特点 | 资产数 |
| --- | --- | --- | --- | --- |
| `family_100.json` | 家庭三居 | 100 ㎡ | 7 个房间分区、8 道内隔墙、5 面外窗，最接近主场景 | 27 |
| `studio_45.json` | 单身公寓 | 45 ㎡ | 9×5 m 紧凑户型，起居/睡眠合一，3 道隔墙 | 20 |
| `loft_open.json` | 开放式 Loft | 96 ㎡ | 12×8 m 大开间、**零隔墙**、3.4 m 挑高、混凝土 + 黑钢 | 25 |

生成 / 重建（每栋独立进程，互不干扰）：

```bash
blpython src/02_scene/assemble.py -- scene/layouts/family_100.json --render
blpython src/02_scene/assemble.py -- scene/layouts/studio_45.json --render
blpython src/02_scene/assemble.py -- scene/layouts/loft_open.json --render
# 或一次全部：
blpython src/02_scene/assemble.py -- --all --render
```

`--render` 可省略（只出 `.blend`，更快）。所有路径都相对项目根，**整个文件夹改名/搬家后命令不变**。

## 三、查资产：拼房前先选积木

```bash
blpython src/02_scene/assemble.py -- --list-categories   # 36 类总览
blpython src/02_scene/assemble.py -- --pick 03           # 看「沙发」4 个变体的 ID / 尺寸 / 材质
```

也可以直接查 `assets/catalog.csv` 或 `docs/02_资产总表.md`。资产 ID 形如 `AST_03_001_沙发_A`，
规则是 `AST_<类别号>_<变体序号>_<中文名>_<变体字母>`，每类固定 4 个变体（A/B/C/D）。
`--pick` 输出的 `dimensions_m` 是真实尺寸（米），用来判断摆得下、会不会穿墙。

> 资产都是 `model.blend`（引用共享 4K 贴图）+ 预览 + 元数据的独立包；组装器从母库按 ID 取用，
> 不降级、不重建、不复制几何。需要把某个资产交给 Unity/Unreal/three.js 时，用 `src/04_tools/export_glb.py` 按需导出自包含 GLB。

## 四、布局 JSON 完整字段

```jsonc
{
  "id": "my_house",                    // 必填，决定输出文件名
  "name": "我的自定义住宅",             // 必填，仅用于说明
  "area_m2": 80,                      // 说明用
  "style": "风格备注",                 // 说明用
  "shell": {
    "x0": -5.0, "x1": 5.0,           // 必填，外墙范围（米），中心可不在原点
    "y0": -4.0, "y1": 4.0,
    "height": 2.8,                   // 层高，默认 2.8
    "wall_thick_ext": 0.24,          // 外墙厚，默认 0.24
    "wall_thick_int": 0.16,          // 内隔墙厚，默认 0.16
    "floor_tex": "oak_wood",         // 默认地面材质
    "wall_tex": "wall_paint",        // 墙面材质
    "ceiling": true                  // 是否生成天花，默认 true
  },
  "rooms": [                          // 可选；仅用于地面分材质 + 标注，不自动建隔墙
    {"name": "客厅", "x0": -5, "x1": 1, "y0": -4, "y1": 0, "floor_tex": "oak_wood"},
    {"name": "卫浴", "x0": 1, "x1": 5, "y0": 0, "y1": 4, "floor_tex": "floor_tile"}
  ],
  "partitions": [                     // 可选；内隔墙线段，可带一个门洞
    {"p0": [1, -4], "p1": [1, 0], "door_at": 0.6, "door_w": 0.9}
  ],
  "windows": [                        // 可选；外墙开窗
    {"side": "south", "from": 0.1, "to": 0.5, "z0": 0.6, "z1": 2.3}
  ],
  "assets": [                         // 核心：要摆哪些积木
    {"asset": "AST_03_001_沙发_A", "pos": [-2, -2, 0], "rot_z": 0, "scale": 1.0, "label": "主沙发"}
  ],
  "camera": {"pos": [8, -9, 6], "target": [0, 0, 1.2], "lens": 24},   // 可选，缺省自动
  "lighting": {"sun": 2.2},                                             // 可选
  "render": {"resolution": [1280, 720], "samples": 24, "exposure": -0.35} // 可选
}
```

### 容易踩的三个约定

| 字段 | 约定 | 说明 |
| --- | --- | --- |
| `rot_z` | **弧度**，不是角度 | 90° = `1.5708`，180° = `3.1416`，−90° = `-1.5708` |
| `windows.from/to` | 沿该面墙 **0~1 比例** | `side` 取 `south`/`north`/`east`/`west`；`z0/z1` 是窗台/窗顶高度（米） |
| `partitions.door_at` | 沿 `p0→p1` **0~1 比例** | `door_w` 是门宽（米），省略则这面墙不开洞 |

### 可用材质名（必须是 16 个之一）

`oak_wood` `walnut_wood` `marble` `linen_fabric` `leather` `brass` `white_ceramic` `rattan`
`brushed_steel` `black_steel` `concrete_floor` `floor_tile` `glazed_terracotta` `painted_wood`
`wall_paint` `wool_fabric`

每个名字对应 `assets/_textures/<材质>/` 下完整的 8 通道 4K 贴图，组装器用 BOX 世界投影，
不依赖 UV、墙段任意切分纹理都连续。

## 五、自己拼一栋新房（5 步）

1. 复制一份示例：`cp scene/layouts/studio_45.json scene/layouts/my_house.json`。
2. 改 `id` / `name`，改 `shell.x0..y1` 定面积与形状，改 `height` 定层高。
3. 按 `rooms` 划分地面材质，用 `partitions` 加隔墙、`windows` 开窗。
4. 用 `--list-categories` / `--pick <类别号>` 挑积木，把 `assets` 换成你想要的 ID 与坐标（`pos` 是世界坐标，z 通常为 0 落地）。
5. 跑 `blpython src/02_scene/assemble.py -- scene/layouts/my_house.json --render`，打开 `scene/assembled/my_house.png` 看效果，不满意就改 JSON 重跑。

**只换一件家具**：把 `assets` 里那一行的 `asset` 换成同类另一个变体 ID 即可，其余不动。
**换一整栋**：改 `shell` 尺寸 + `partitions` + `assets`，同一套 144 个资产反复复用，无需新增任何模型。

## 六、与主场景 `house.blend` 的关系

- `build_house.py` → `scene/house.blend`：把房型、隔墙、107 个摆设写死在代码里的**固定成品住宅**，质量基准与渲染母本。
- `assemble.py` → `scene/assembled/*.blend`：**参数化、可任意变体**的组装产物，二者共用同一个母库与同一套 4K 贴图。
- 想做「和视频一样的高完成度固定样板房」用前者；想「快速拼出不同房屋 / 批量出方案」用后者。

## 七、产物与可迁移性

- `scene/assembled/` 里的 `.blend` 把用到的资产 Collection **内嵌**进文件，4K 贴图仍以 `//` 相对路径引用 `assets/_textures/`。整个 `house-building/` 一起搬走即可正常打开；单独拷 `.blend` 需按 `08_迁移指南.md` 带贴图或跑 `relink_all.py`。
- 组装产物是**可再生的**：删掉整个 `scene/assembled/` 后重跑布局即可完全重建，不会破坏任何源码或资产。
- 校验：`python3 src/04_tools/migrate_check.py` 会检查目录树与三件套；组装器本身不改动母库、贴图或任何既有资产。
