## 设计说明

- 风格：温暖日光 · 现代自然风（橡木地板 / 暖白墙 / 亚麻软装 / 黄铜五金 / 绿植），与参考视频的雨夜暗调厨房明确区分。
- 南侧客厅与餐厨连续大窗引入主日光；主卧设西侧窗；东侧书房、阳台开窗。
- 内墙开门洞形成玄关→走廊→各房间的动线；卫浴与书房独立分隔。
- 家具全部以 `asset_library.blend` 的 Collection 实例引用，不重造几何。
- 生活化不规则细节：半开的卫浴门与书房门、随手搭放的毛巾与书本、台面错落摆放的罐与锅、窗台小盆栽（Q11）。
