# 快速开始

## 1. 依赖

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Python | 3.11 | 全部脚本 |
| `bpy` | 4.5.x | Blender headless 建模 / 渲染（**需要 blpython 环境**） |
| `numpy` / `Pillow` | 任意较新版本 | 贴图生成、检视图、预览拼图 |
| Blender glTF 导出器 | bpy 内置 | 仅按需导出 GLB（见 §6，默认不生成） |

安装（示例，Linux）：

```bash
python3.11 -m venv .venv && . .venv/bin/activate
pip install bpy==4.5.15 numpy pillow
```

> 下文所有 `blpython` 指「装了 bpy 的那个 Python」；纯 Python 脚本用 `python` 即可。
> 项目不依赖任何绝对路径，虚拟环境放哪都行。

## 2. 流水线（按顺序）

```bash
cd house-building          # 或任何你改名后的位置

# ① 贴图：16 材质 × 8 通道 × 4096²（不传参数=全量；也可只跑单材质）
python src/00_textures/make_ai_textures.py
python src/00_textures/make_ai_textures.py oak_wood

# ② 检视图
python src/00_textures/texture_sheets.py

# ③ 资产母库：36 类 / 144 个 AST_ collection
blpython src/01_assets/build_library.py

# ④ 拆成 144 个独立可迁移资产（三件套；-- 后可指定类别号，便于分批）
blpython src/01_assets/export_assets.py
blpython src/01_assets/export_assets.py -- 01 02 03

# ⑤ 100 ㎡ 住宅
blpython src/02_scene/build_house.py

# ⑥ 出图
blpython src/03_render/render.py house       # 6 机位
blpython src/03_render/render.py house:bedroom,kitchen   # 只补渲指定机位
blpython src/03_render/render.py closeup    # 5 张资产特写
blpython src/03_render/render.py hero       # 3840×2160 主图（分块渲染再拼接）

# ⑦ 自检
blpython src/04_tools/verify.py            # → scene/verify_result.json
python src/04_tools/migrate_check.py       # 结构 / 可迁移性自检
```

各脚本开头都会自动向项目根插入 `config.py` 所在目录，因此**从任意工作目录、
任意文件夹名**直接调用都可以。

## 3. 只改局部时怎么办

| 改动 | 最小重跑范围 |
| --- | --- |
| 调某个材质的贴图 | `make_ai_textures.py <材质>` → `texture_sheets.py` |
| 调某个资产的几何 | `build_library.py` → `export_assets.py -- <类别号>` → `build_house.py` → 相关机位 |
| 调家具摆位 / 建筑收口 | `build_house.py` → `render.py house` |
| 调灯光 / 曝光 | `render.py`（也可只跑 `house:living` 快速看效果） |
| 搬项目 / 改目录 | `migrate_check.py`；异常时 `relink_all.py` |

## 4. 渲染说明

- 无 GPU，Cycles **CPU** + OIDN 降噪，静帧为主。
- 4K 主图用 2×2 分块渲染再无损拼接（单进程直渲 4K 会触发内存上限）。
- 资产预览用 **Cycles 12 采样 + OIDN 降噪**（浅灰摄影棚 + 主光 / 补光），单张约
  3–4 秒，能真实呈现木纹 / 织物 / 金属 / 陶瓷差异；`diffuse_color` 按 4K albedo
  平均色写回，任意视图模式下颜色都与贴图一致。

## 5. 出问题先看这里

| 现象 | 原因 / 处理 |
| --- | --- |
| 贴图全黑 / 粉红 | 路径断了 → `blpython src/04_tools/relink_all.py` |
| `import config` 失败 | 脚本被单独拷出了项目树 → 保持整个文件夹结构，或设 `HOUSE_BUILDING_ROOT` |
| 想拿资产到别的软件 | 用 `export_glb.py` 按需导出自包含 GLB，见 §6 |
| 想拼一栋不同的房屋 | 用 `src/02_scene/assemble.py` + 布局 JSON，见 §7 |
| `.blend` 打开报缺库 | `scene/house.blend` 通过 Collection Instance 引用母库，保持 `_library/` 存在 |

## 6. 可选：按需导出 GLB

默认流水线只产 `model.blend`（完整 4K PBR），不生成重复的 glTF 副本。
需要把资产交给 Unity / Unreal / three.js / 网页查看器时，临时导出内嵌 1K 贴图
的自包含 GLB，用完可删：

```bash
blpython src/04_tools/export_glb.py -- AST_01_001_餐椅_A     # 单个资产
blpython src/04_tools/export_glb.py -- 01 03 07              # 按类别号
blpython src/04_tools/export_glb.py -- all                   # 144 个全量
```

## 7. 任意组装成不同房屋（可选）

工程不止一栋固定住宅。`src/02_scene/assemble.py` 读一份声明式布局 JSON，
从母库按 ID 实例化资产、用共享 4K 贴图生成壳体，输出一栋全新的房屋：

```bash
blpython src/02_scene/assemble.py -- --list-categories       # 36 类总览
blpython src/02_scene/assemble.py -- --pick 03               # 查沙发 4 个变体 ID / 尺寸
blpython src/02_scene/assemble.py -- scene/layouts/studio_45.json --render
blpython src/02_scene/assemble.py -- --all --render          # 重建 3 栋示例
```

复制 `scene/layouts/*.json` 改面积 / 隔墙 / 资产清单即可拼自己的房型，
完整字段见 `docs/09_任意组装指南.md`。产物落在 `scene/assembled/`（可再生）。
