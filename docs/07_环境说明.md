# 环境说明

## 1. 运行依赖

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Python | 3.11 | 全部脚本 |
| `bpy` | 4.5.x | Blender headless 建模 / 渲染 |
| `numpy` / `Pillow` | 较新版本 | 贴图生成、检视图、预览拼图 |
| GPU | 无 | Cycles CPU + OIDN 降噪 |

下文 `blpython` 指「装了 `bpy` 的那个 Python」。纯 Python 脚本（贴图生成、
检视图、迁移自检、双图对比）用系统 `python` 即可，不需要 Blender。

## 2. 一次装好

```bash
python3.11 -m venv .venv && . .venv/bin/activate
pip install bpy==4.5.15 numpy pillow
```

虚拟环境放哪都行：项目不依赖任何绝对路径，脚本会自己向上找 `config.py`。

## 3. 通路验证

```bash
blpython src/04_tools/env_probe.py
```

探针检查建模 / Bevel / WeightedNormal modifier / Principled BSDF 节点连线 /
Cycles CPU 渲染通路，并输出一张验证图到
`renders/04_材质检视/env_check.png`。该图只是探针产物，不属于交付成果，
可随时删除。

## 4. 已知约束

- `bpy` 是 **Python 模块形态**，不是 Blender 可执行文件。调用本项目脚本一律用
  `blpython src/...py`，不要写成 `blender -b xxx.blend -P script.py`——那样
  `.blend` 会被当成 Python 文件解析并报编码错误。
- 无 GPU，只渲染静帧；4K 主图用 2×2 分块渲染再无损拼接，单进程直渲 4K
  会触发内存上限。
