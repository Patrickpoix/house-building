## 2. 工程结构

### 2.1 资产可见、可单独取用

`by_category/` 下 36 类 → 144 个资产都是真实目录，每个含完整 4K PBR；母库
`asset_library.blend` 只作为场景 Collection Instance 的引用源保留在 `_library/`。

```
assets/by_category/
├── 01_Seating_餐椅/          ← 36 个类别目录，可直接数出
│   ├── README.md              ← 本类 4 变体对照表
│   ├── preview.png            ← 4 变体 2×2 拼图
│   └── AST_01_001_餐椅_A/     ← 144 个资产目录，每个一份完整 PBR
│       ├── model.blend        ← 资产本体：完整 4K PBR（// 相对路径引用共享贴图）
│       ├── preview.png        ← Cycles 真实材质预览
│       └── meta.json          ← 尺寸 / 材质 / 部件 / 顶点 / 依赖贴图
```

校验：`category_dirs=36`、`asset_dirs=144`、三件套各 144、`missing_total=0`。

### 2.2 零硬编码与路径统一

- `config.py` 作唯一路径源，用 `Path(__file__).resolve().parent` 推导 ROOT，
  支持 `HOUSE_BUILDING_ROOT` 环境变量覆盖。
- `src/` 下 16 个脚本全部 `import config as C`；全项目 `.py` **0 处**绝对路径字面量。
- 所有 `.blend` 内贴图由 `config.rel()` 统一计算成 `//` 相对路径；
  `relink_all.py`（批量修复）与 `migrate_check.py`（搬家自检）配套。

### 2.3 目录分层

- `src/` 按流水线分 5 个阶段子目录；`renders/` 按 4 类用途分目录；
  `assets/` 分 `_textures` / `_library` / `by_category`；贴图按 16 材质分目录。
- 每个资产只存一份几何 + 一套完整 4K PBR，不重复存内嵌 1K 缩略贴图的 glTF
  副本；不保留历史基线与版本对比目录。需要跨软件单文件复用时用
  `export_glb.py` 按需导出，需要双图对比时用 `compare.py` 并自行指定输出路径。
- 9 份文档，`docs/01_目录规范.md` 给接手 agent 看，`docs/09_任意组装指南.md` 讲如何拼不同房屋。

## 4. 资产预览

- `preview.png` 用 **Cycles 12 采样 + OIDN 降噪**，浅灰 world + 主光 / 补光摄影棚，
  单张约 3–4 秒，能真实呈现木纹、织物、金属、陶瓷差异。
- `set_material_display_colors()` 按各材质 4K albedo 平均色写回 `diffuse_color`，
  使 Workbench / 实体等任意视图模式下颜色都与真实贴图一致。
- 不再为每个资产预生成 glTF 缩略副本：144 份内嵌 1K 贴图的 GLB 与
  `model.blend` 几何完全重复、合计约 500 MiB，已删除。需要时按 `08_迁移指南.md`
  用 `export_glb.py` 按需导出。

`renders/04_材质检视/36类资产总览.png` 可一眼验收 36 类：形状可辨、材质色
区分明显、浅灰背景统一、无黑块与纯灰模。

## 5. 环境与替代声明

| 原指令 / 视频管线 | 实际采用 | 影响 |
| --- | --- | --- |
| `image2.6` 生成参考图 | 无该模型，改用可用图像生成能力 + 视频关键帧 | 几何由参数化脚本驱动 |
| `Tripo` 生成 PBR 模型 | 无 API key 且模型源不可达，改用 `bpy` 程序化曲面建模 | 可复现、细节密度可控，但缺 AI / 扫描高模的有机不规则形态 |
| GPU / Cycles 高质量渲染 | Cycles CPU + OIDN，静帧 | 采样与分辨率受限 |
| 扫描级法线烘焙 | 高度场微分生成法线 | 非高模雕刻烘焙 |

## 6. 质量边界

1. **法线**来自高度场微分，不是高模雕刻烘焙。
2. **几何**是参数化曲面 + fBm 扰动，形态仍比手工雕刻规整，缺随机磨损。
3. **合成材质**中釉面陶土 / 刷漆木 / 乳胶漆观感偏平；俯视全景下木纹平铺
   重复感可见。
4. **材质 Displacement** 节点仍以 BUMP 为主；真实几何位移由 205 个部件的
   DISPLACE 修改器承担。
5. **无 GPU**，只交付静帧，无漫游动画与剪辑。
6. **跨软件单文件格式为按需导出**：默认只交付 `model.blend`（完整 4K PBR），
   不预生成 GLB；需要时用 `export_glb.py` 导出内嵌 1K 贴图的自包含副本。
