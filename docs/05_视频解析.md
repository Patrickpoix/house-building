1. 资产是**可复用的模块**，不是一次性场景物件 → 需独立 Collection + 清单
2. 数量有明确规模（36 类 / 143 模块）→ 数量下限

5. 场景是从资产库**装配**出来的（S002 模块重建），不是重新建模 → Q13 的依据
6. 灯光与镜头服务于展示资产 → 需要能看清材质的出图
